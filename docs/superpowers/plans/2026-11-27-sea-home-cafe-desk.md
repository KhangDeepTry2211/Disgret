# Sea home, café looks and Gret at a desk (spec 019) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, as for the
> rest of the redesign). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** During a session Gret works at a desk (writing, typing, reading in turn) in the sea and in
Quán San Hô; the café is redrawn cosy in soft 3D with a second diorama look chosen in Góc của Gret;
Hôm nay's sea is redrawn in soft 3D with Gret's shell house, four decoration spots and late-night
sleep.

**Architecture:** Pure rules in `lib/data/` (`GretWork.taskAt`, decoration catalog, `CafeLook`,
late-night window). Props are SVGs generated by `specs/019-sea-home-cafe-desk/scene_art.py`, which
reuses the shape and soft-shading helpers of `specs/018-mascot-family/mascot_art.py`; a new
`MascotAtDesk` widget stacks `MascotView`, a desk SVG and an animated prop. Painters keep water,
sky, light and floors, redrawn with gradients; scene props are SVG widgets over them.

**Tech Stack:** Flutter 3.50, Riverpod 3, Hive, flutter_svg; Python generator (not shipped).

**Spec:** `specs/019-sea-home-cafe-desk/spec.md`

## Global Constraints

- Shared 240×200 mascot canvas unchanged; the desk covers the mascot below 0.76 of its height so
  eyes, cheeks and mouth (0.52–0.68) stay visible.
- Colours only in SVGs and `AppSea`/`AppCafe` tokens; UI text in `AppStrings` (Vietnamese).
- Reduced motion: every loop shows its still pose (Gret writing, page open, no steam).
- Unknown stored ids/enums map to defaults (no decoration, cosy café).

## Review Focus

- Every species and drawing style at the desk: props move, limbs never drawn per species.
- Break during a session: Gret sleeps at the desk without a prop.
- Large text / small phone: the desk scales with the scene; the ring and bubbles never covered.
- A decoration whose spot is taken replaces the old one (like outfits per slot).
- 23:00–05:59 only on Hôm nay outside a session; a running session always shows the desk.

### Task 1: Gret's work loop and desk
**Files:** `lib/data/gret_work.dart` (new: `enum WorkTask { writing, typing, reading }`,
`enum DeskKind { coral, wood }`, `GretWork.taskAt(Duration focused)` changing every 2 min of
session time); `lib/widgets/mascot/mascot_at_desk.dart` (new); `SeaScene(work:)`,
`SeaCafeScene(work:)`, `focus_screen.dart`, `cafe_session_view.dart`; art `assets/scene/desk_*`,
`notebook`, `pen`, `laptop`, `book`, `book_page`. Tests: `test/gret_work_test.dart` (rule, every
task and break render), focus/café widget tests find `MascotAtDesk`.

### Task 2: Cosy café redraw
**Files:** `sea_cafe_painter.dart` (wallpaper, wood panel, tiled floor, beams/glows), café props SVGs
(counter with kettle and menu board, round table with chairs, subject props, hanging plant,
curtains, string lights), `sea_cafe_scene.dart` (friends seated behind table fronts). Tests: café
view tests still pass; table fronts drawn above friends.

### Task 3: Sea redraw and Gret's home
**Files:** `sea_painter.dart` / `sea_scenery.dart` (gradient water, caustics, sand ripples and
shells, rounded outlined seaweed and coral, chibi fish, glossy bubbles, sun and moon glow);
`assets/scene/home_*` (shell house, sign, chest); `SeaScene` draws the home on Hôm nay and in the
sea session.

### Task 4: Decorations and late-night sleep
**Files:** `gret_corner_catalog.dart` (`DecorSpot`, `DecorationInfo`, six items 40–150 pearls),
repository `corner_decor`, notifier `place`/`remove`, Góc của Gret → Biển section "Trang trí",
`SeaScene` draws placed items; `SeaTime.isLateNight` (23:00–05:59) and Hôm nay's mood. Tests:
catalog, storage, notifier, sheet, late-night rule.

### Task 5: Diorama café and "Kiểu quán"
**Files:** `CafeLook { cosy, diorama }` in the corner state and repository, chips in Linh vật under
"Nét vẽ", `SeaCafeScene` diorama layout (isometric room SVG, positions). Tests: choice persists,
café view uses the diorama.

### Task 6: Gates and docs
`dart format`, `flutter analyze`, `flutter test`; spec status, tasks.md, design-system section,
